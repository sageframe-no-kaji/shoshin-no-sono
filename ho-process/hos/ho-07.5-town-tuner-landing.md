# ho-07.5 — Town tuner landing: the by-feel pass, in the practitioner's hand

## Problem

ho-07 built the towns and explicitly left the deform *feel* and the placement tuners as the practitioner's by-feel pass on `:8788`, not closed on the model's eye (the ho-06.5 discipline). The Think-phase defaults had already been moved once during ho-07's execution — a seed-sweep against the overview's named placement criteria (three-hours → Hōzō, the-empty-container → Glassroom, the-same-lever → central) landed `anchorBias` 4 / `strengthFull` 3 / `footOffset` 20, and the mechanism fixes from the live pass re-modelled the seat descent, the contour-follow drape (to 0–1 strength), added overlap relaxation, and pulled a minimal peak-label render forward. But the *verdict* — does the assembled map read right under the practitioner's eye — was still open. This ho records that verdict.

## Solution

The practitioner ran the full by-feel pass across several seeds and filter states on the live instrument and **confirmed** the town tuners at their source values — the sweep-landed defaults held under his own eye. The only value that moved was the label size, dialed down because the type spec's sizes were solo-plate scale and overpower the assembled 19-peak map. The line-weight drop was explored (0.1 / 0.35) and **declined** — the frozen register weights (0.25 / 0.7) stand, so there is no register revision.

This is the inverse of ho-06.5, where the practitioner's pass moved every field default away from the model's premature verdict. Here the model's values were dialed to *named, written* criteria (not an aesthetic guess), and the practitioner's eye confirmed them — so the landing is a confirmation, with one typographic adjustment.

## Changes

- **`src/cartography-page.js`**: `labelScale` default 0.8 → 0.6. The town and field tuners already held these values in source (set during ho-07 execution), so no other default moved.
- **No register revision**: the line-weight drop was explored on the live sliders and declined; `contour-map.js` `REGISTER` (0.25 / 0.7) is untouched, and the frozen visual register stands.
- The label layer still lives on the debug page (coverage-excluded glue); the landed `labelScale` 0.6 is a typography finding ho-09 inherits when it builds the real label layer.
